# FreeWriting — GitHub Pages

このZIPの中身をGitHubリポジトリのルートにアップロードしてください。
`index.html` がルートに置かれるようにします。

Settings → Pages → Deploy from a branch → main / (root) → Save

ビルドやインストールは不要です。すべてのパスは相対パスです。
文章はブラウザ内に保存され、外部には送信されません。
